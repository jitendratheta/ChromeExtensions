# Link Hover Preview

Hover a link for about a second and a popup preview of the linked page appears next to it.

## Install

1. Open `chrome://extensions`.
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and pick this folder.

## Use

- Hover a link and wait for the delay (1000 ms by default).
- Move the mouse into the popup to scroll or click inside it.
- Move away, scroll the page, click elsewhere, or press Esc to close it.
- **Open ↗** opens the link in a new tab.

## Settings

Click the toolbar icon (or the extension's Options):

- Enable or disable previews
- Hover delay in ms
- Popup width and height in px, with Small / Medium / Large / XL presets
- Force-load sites that block embedding (off by default, see the note on the settings page)
